# Purchase sharing

**Compare saved purchases** checks the selected Humble account against Galactic Library without changing either library. The summary distinguishes matching purchase/title coverage, differences, incomplete comparisons and failed checks. Different totals do not prove purchases are missing: HB can combine several purchases in one library entry, while GL can keep separate download and key records. Uncertain matches and category differences remain visible.

**Preview transfer** shows potential changes without importing anything or sending an offer. New title names are distinguished from additional purchase records by saved names, not edition or ownership decisions. GL previews separate information changes from last-checked time updates. HB previews cannot yet distinguish these update types and use conservative wording. Both directions still require account confirmation before sending or importing. Expand **Technical details** for exact counts and reasons; **Export comparison report** retains the full private report with hashed purchase references. Category differences are review notices, not necessarily skipped imports.

On the signed-in Humble Purchases page, **Refresh missing product IDs** previews affected saved orders and asks for explicit confirmation of the active account. A normal v9 backup downloads before acquisition. The existing scraper reads only those purchase keys, with its existing redaction and pacing. A unique exact purchase/title/media/delivery association can fill an absent source product ID. Existing native IDs, purchase dates, bundles, titles, histories, ownership, reminders and manual corrections remain intact. Single-origin source-attributable rows can also fill missing bibliographic fields. Changed titles, ambiguous candidates, positional fallbacks and conflicts remain unresolved. No new purchases are imported or deleted.

Use **Cancel metadata refresh** to retain the original library. Staged evidence is saved once through the validated atomic writer; closing the tab or a failed save preserves original rows. A request-error count does not mean every unresolved ID failed. The completion report distinguishes recovered, unavailable, ambiguous/conflicting and historical fills. Backup version remains 9. Then refresh account choices and run Reconcile/Preview again; no transfer starts automatically.

Open Options -> Galactic Library connection -> Purchase sharing. Account choices load automatically when opened. Choose Send or Import, select the source and destination accounts, and confirm they represent the same store account. Equal nicknames do not prove identity. A new nickname is requested only for a new separate destination.

Import transfers, validates and commits supported saved purchases here. Send opens Galactic Library with an offer and the selected destination; complete the receiving review and Import confirmation there. An offer is not a completed import. Progress and committed counts show what actually happened. Use Refresh account choices after changing either saved library.

Check connection verifies communication only. Bundle matching uses GL's additional ownership evidence; refresh an already-open bundle page after connecting. Checking a connection or refreshing a bundle never transfers purchases.

Local, empty, archived and older accounts remain visible even if GL is unavailable. Eligibility limitations are separate from account discovery. Older Humble purchases without native product IDs can only enrich an unambiguous existing GL purchase/title. Unmatched rows are skipped. Missing Fanatical product identity is excluded and reported; primary bundle data is retained when historical order references are unavailable. No identity is guessed.

Official builds connect by published ID. For unpacked builds, allow this extension's ID in GL Advanced pairing and enter GL's ID here. Update both extensions for the purchase-sharing protocol. GL verifies responding authorized IDs; it does not trust an ID claimed in a message. Missing, disabled and incorrectly addressed extensions can produce the same browser error.

Transfers preserve richer data, merge supported purchases without deletion and are idempotent. They do not establish a complete scan/reminder baseline. Retry after refreshing choices if staging expires or a source worker restarts. No library is partially imported. Normal standalone imports still work without GL.

Developer UI policy: prefer ASCII control, navigation, status and button text; write UTF-8. Do not substitute question marks for decorative separators or use unverified symbols. Unicode titles, authors and user metadata remain supported. Shared control-text integrity checks and native package checks guard known corruption.
