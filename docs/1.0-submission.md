### Game bundle defect in candidate 5

On Humble's redesigned game bundle pages, candidate 5 listed three page controls (Select your bundle, Bundle Details, Adjust Donation) as New items and showed no game badges. Book and software bundles were not affected.

- Redesigned game cards hold their cover image in `product-thumbnail`; book and software cards use `bundle-item-native-image`, the only container the cover selector accepted. No game covers were found.
- With no covers, the heading fallback accepted any `h2`–`h4` with an ancestor class containing "item". Humble's utility class `lg:items-start` matches, so page headings became items.
- The redesign adapter (`67815d2`, 2026-11-11; in no published version) was developed against book pages; its game test reused the book card markup. Published 1.0.3 predates the adapter and shows the same three items on every redesigned bundle page, books included.

Corrected behavior: covers are read from either container; redesigned pages take items only from bundle cards, never from headings; and if any card has no readable title, the page states that ownership could not be checked and shows no summary or badges instead of a partial list. `tests/redesign-games-fixture.html` reproduces the observed game-page structure (synthetic titles), and `node tests/browser.mjs --redesign-games` fails on the candidate 5 `content.js`.

### Known issues and limitations

- After client-side navigation between bundles, item lists, badges and totals are correct but the per-tier breakdown is not shown until a reload or direct load. Humble delivers the new page's data by fetch rather than in the document, and data from the previous page is deliberately not reused. Applies to all bundle types; unchanged from candidate 5.
- Dotted and undotted acronyms are different titles for matching: a saved "F.E.A.R. 2: Project Origin" shows New for Humble's "FEAR 2: Project Origin". This misses ownership rather than claiming it; matching rules are unchanged.
- Without Galactic Library installed, unowned software items show Check incomplete instead of New. The software capability request to Galactic Library runs before the availability check, and its failure is treated as an incomplete lookup. Present since October 2026 (`e3dc1f0`) and in published 1.0.2 and 1.0.3; it never claims ownership. Not changed in this release.
- Partial is not exercised live on game pages; it requires reviewed collection contents and is covered by the redesigned book fixture.
