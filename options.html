Humble Comic Library

Your library stays in this browser. Import directly from your signed-in Humble purchase history or restore a JSON backup.

Import from Humble

Sign in to Humble in this browser, open the purchase importer, and select Import new purchases. Use Rescan all purchases to rebuild the active account's snapshot from the full purchase history.

How account nicknames work

A nickname labels a website account locally; it does not detect your login. Use Saved accounts to switch to an existing snapshot without a full rescan. Rename account changes only its name and preserves scan history. For a new account, sign in on the website, enter a new nickname in the importer, select Save a new account, and rescan all purchases once. Only the active account is matched; other saved accounts are kept separately.

Not yet named means no account nickname has been established. Confirm a nickname in the importer; the first import automatically requires a full scan.

Wishlist and priorities

Add titles here or use Wishlist in a bundle summary. Priority is your preference from 1 to 100; higher priorities matter more in purchase plans. Wishes do not establish ownership.

What happens after I add a wish?

When you open a supported bundle, the extension compares its items with your saved wishes. Choose the Wishlist purchase goal to see the lowest tier or selection that covers eligible wishes and the priority available at each price. Owned items are excluded; uncertain matches are excluded unless you include them. A wish may have no eligible target in the bundle you opened.

The extension does not monitor new bundles or send wishlist notifications. Wishlist entries and priorities are local to this extension and are not shared with the other extension or Galactic Library.

    Galactic Library connection

    Official GalacticHamster extensions connect automatically. Check the connection, then refresh your bundle page. Checks send bundle titles and available identity/contents evidence; results contain matching titles and safe reminders, never the full library. Books/comics, audiobooks, games and supported software are checked separately.

        Advanced: manual title imports and collection mappings (Humble only)

        These tools support manually curated libraries and reviewed comic collection contents. Fanatical uses its product records and linked Galactic Library instead.

        Import titles

        Choose a manual JSON title list: an array of strings or objects with title, optional sourceBundle, and optional kind. This replaces the library and removes all saved accounts, purchase records, provenance, reminders, scan history, the history archive, and custom mappings. To recover exported purchase data, use Restore backup.

        Collection mappings

        Import reviewed issue/volume-to-collection rules. Edition identifiers, series/run IDs, annuals, specials, fractional issues, source evidence, and partial reprints are supported. Unreviewed rules and excerpts never prove full ownership. Expand the format help below for an example you can use without leaving the extension.

        Collection mapping format and review requirements

        A mapping links a collection title to the issues or volumes it contains. Import a JSON array of rules. Replace the example title, series, run, language and range with the actual edition's contents. The example starts unverified; it cannot establish ownership.

        [{
  "id": "example-collection",
  "collectionTitle": "Example Series Collection",
  "verified": false,
  "contentsComplete": false,
  "contains": [{
    "series": "Example Series",
    "run": "2020",
    "language": "en",
    "unitType": "issue",
    "from": 1,
    "to": 6,
    "completeness": "full"
  }]
}]

        Only set verified: true after checking this edition's contents against a reliable source. Record sourceLabel, an optional public sourceUrl, and an ISO verifiedAt date. Set contentsComplete: true only if the list covers the entire collection. Use completeness: "excerpt" for partial reprints. Runs, languages, issues, volumes, annuals and specials remain separate; unreviewed rules and excerpts never prove full ownership.

        Privacy

        Your library, wishlist and preferences stay in this browser. Galactic Library linking exchanges only the match or reminder evidence needed for the action you request; neither full library is transferred.

        Humble imports use the website's signed-in session without copying cookies or storing redemption-key values. Local records and backups retain purchase identifiers and provenance for recovery and reminder navigation. Keep backups private. Direct order links are optional because their purchase identifiers can appear in browser history.
