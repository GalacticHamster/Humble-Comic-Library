Your library stays in this browser. Import directly from your signed-in Humble purchase history or from a JSON backup.

Import from Humble

While signed into Humble in this browser, open your Purchases page and select Import new purchases. It skips orders already imported locally; use Rescan every purchase only when you need to rebuild the Humble library.

Wishlist and priorities

Add titles here or tick Wishlist beside a bundle summary item. Priority is your personal weight from 1 to 100, not a price estimate. Bundle plans exclude owned items and uncertain matches unless you include them.

    Galactic Library link

    Check current bundle games, software, books, and audiobooks against Galactic Library. Exact ownership, related editions, and reviewed collection contents are supported; ebooks and audio remain separate. Software lookup is enabled only when Galactic Library advertises software support. Requests include current bundle titles, media types, available catalog evidence, and explicit contents lists. They exclude Humble records to avoid stale duplicates and never transfer either full library.

    Share entitlement reminders

    Send safe key statuses to the linked Galactic Library in batches of 200. This sends titles, media types, opaque references, status and reported dates; no keys, order IDs, purchase links or prices. Destination activation remains unknown and this feed never establishes ownership. Sending is manual, not automatic.

    Key reminders

        Restore backup

        Choose an exported Humble Comic Library backup. Restore replaces all items, purchase records, provenance, key reminders, scan history, the history archive, and custom mappings. Your wishlist, browser preferences and Galactic Library connection stay as they are. Older backups clear data they do not contain.

        Import titles

        Choose a manual JSON title list: an array of strings or objects with title, optional sourceBundle, and optional kind. This replaces the library and clears purchase records, provenance, reminders, scan history, the history archive, and custom mappings. To recover exported purchase data, use Restore backup.

        Collection mappings

        Import reviewed issue/volume-to-collection rules. Edition identifiers, series/run IDs, annuals, specials, fractional issues, source evidence, and partial reprints are supported. Unreviewed rules and excerpts never prove full ownership. See the README for the JSON format.
