Humble Comic Library

Your library stays in this browser. Import directly from your signed-in Humble purchase history or from a JSON backup.

Import from Humble

While signed into Humble in this browser, open your Purchases page and select Import new purchases. It skips orders already imported locally; use Rescan every purchase only when you need to rebuild the Humble library.

Key reminders

Track Humble third-party entitlements that have not yet been revealed. Imports check new purchases and pending entitlements; a full rescan establishes the complete reminder baseline. Redemption-key values are never stored.

Off by default: Open purchase uses Humble's normal purchase-card flow, so allow pop-ups and redirects for Humble if you want it to open the individual order. When enabled, the purchase identifier appears in the Humble URL and browser history.

    Import titles

    Choose a manual JSON title list: an array of strings or objects with title, optional sourceBundle, and optional kind. This replaces the library and clears purchase records, provenance, reminders, scan history, and custom mappings. To recover exported purchase data, use Restore backup.

    Collection mappings

    Import optional issue-to-collection rules. Rules stay in this browser and only mark an issue Owned when the named collection is already in your library.

    Restore backup

    Choose an exported Humble Comic Library backup. Restore replaces all items, purchase records, provenance, key reminders, scan history, and custom mappings. Browser preferences and your Galactic Library connection stay as they are. Older backups clear data they do not contain.

    Galactic Library link

    Optionally check a current Humble bundle against exact game and book titles owned through your other connected libraries. This sends only the bundle titles being checked to your locally installed Galactic Library extension; it never transfers either full library.
